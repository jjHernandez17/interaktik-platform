Conecta tu juego

Elige tu edición de Minecraft. Solo juegas tú en el mundo; no necesitas pagar ningún servidor.

¿Cuál tengo? Java Edition es el que abres con el launcher de Minecraft en PC (Windows, Mac o Linux). Bedrock Edition es el de celular, consolas y "Minecraft para Windows" de la Microsoft Store. Cada uno usa un comando distinto: si pegas el de Bedrock en Java, Minecraft responde "Comando desconocido o incompleto".

Solo para Minecraft Bedrock. En Java este comando no existe: usa la pestaña Java.

  1. Abre tu mundo con los trucos activados (en los ajustes del mundo, "Activar trucos").
  2. Pega este comando en el chat del juego y pulsa enviar:
  3. Listo: verás "Interaktik conectado ✔" en pantalla y el estado de arriba pasará a "Conectado".
  • Si sales del mundo o cierras el juego, vuelve a pegar el comando.
  • Con los trucos activados el mundo no da logros.
  • Funciona en Windows, Android y iOS. En consolas ese comando puede no estar disponible.
  • En Bedrock los lobos no salen domados y el TNT sí rompe bloques.

Mundos de un jugador Recomendado · sin servidor

Un mod de Fabric (1.21.x) que conecta tu mundo con la plataforma. Solo juegas tú, no hace falta ningún servidor.

  1. Instala Fabric y Fabric API (una sola vez): Fabric Fabric API
  2. Descarga el mod y ponlo en la carpeta mods de Minecraft: Descargar mod (.jar)
  3. Abre tu mundo y pega este comando en el chat (solo la primera vez; después se conecta solo):
  • Otros comandos del mod: /interaktik estado y /interaktik desconectar. No necesitas trucos activados.
  • También funciona en un mundo abierto a LAN o en un servidor Fabric.

Si ya tienes un servidor Plugin para Paper

Para servidores Paper o Purpur (1.20 o superior). Solo lo instalas una vez.

  1. Descarga el plugin Descargar plugin (.jar)
  2. Cópialo a la carpeta plugins de tu servidor y reinícialo una vez.
  3. Pega esta llave en plugins/Interaktik/config.yml (campo server-key) y ejecuta /interaktik reload.
  4. Escribe aquí tu nombre en Minecraft: a ese jugador se le aplican las acciones.

Si regeneras la llave, la anterior deja de funcionar: tendrás que volver a pegar el comando (Bedrock o mod de Java) o la llave (plugin).
